# Titanic — Machine Learning from Disaster

## Português

Este projeto prevê a sobrevivência de passageiros do Titanic com classificação binária. O repositório foi organizado como uma sequência curta de notebooks: cada um tem uma responsabilidade clara, documentação em português e inglês e pode ser revisado diretamente no GitHub.

### Fluxo do projeto

| Ordem | Notebook | Responsabilidade |
| --- | --- | --- |
| 1 | `notebooks/01_exploracao_dados.ipynb` | Conhecer as bases brutas, qualidade dos dados e hipóteses iniciais. |
| 2 | `notebooks/02_preparacao_atributos.ipynb` | Limpar dados, criar atributos e salvar as tabelas preparadas. |
| 3 | `notebooks/03_modelagem_selecao.ipynb` | Comparar modelos, ajustar o Random Forest e salvar o modelo final. |
| 4 | `notebooks/04_geracao_submissao.ipynb` | Prever a base de teste e gerar `resultados.csv`. |

Execute os notebooks nesta ordem, a partir da pasta `notebooks/`. O notebook original (`ML.ipynb`) foi mantido apenas como histórico; os notebooks acima são a versão organizada e devem ser usados como referência.

### Estrutura

```text
DATA/
  train.csv                  # dados rotulados / labeled data
  test.csv                   # dados para previsão / prediction data
  processed/                 # gerado pelo notebook 02 / generated by notebook 02
notebooks/                   # análise e processo documentados / documented workflow
artifacts/                   # modelo treinado, gerado pelo notebook 03 / generated by notebook 03
resultados.csv               # submissão, gerada pelo notebook 04 / generated by notebook 04
```

Os diretórios `DATA/processed/` e `artifacts/`, assim como `resultados.csv`, são produtos reproduzíveis e não são versionados.

## English

This project predicts Titanic passenger survival using binary classification. The repository is organized as a short notebook sequence: each notebook has a clear responsibility, bilingual documentation, and is easy to review directly on GitHub.

### Project flow

| Order | Notebook | Responsibility |
| --- | --- | --- |
| 1 | `notebooks/01_exploracao_dados.ipynb` | Inspect raw datasets, data quality, and initial hypotheses. |
| 2 | `notebooks/02_preparacao_atributos.ipynb` | Clean data, engineer features, and save prepared tables. |
| 3 | `notebooks/03_modelagem_selecao.ipynb` | Compare models, tune Random Forest, and save the final model. |
| 4 | `notebooks/04_geracao_submissao.ipynb` | Predict the test set and generate `resultados.csv`. |

Run the notebooks in this order from the `notebooks/` directory. The original notebook (`ML.ipynb`) is retained only as historical reference; use the notebooks above as the organized workflow.

## Evaluation

The Kaggle competition evaluates submissions with accuracy. Validation in notebook 03 is kept separate from the competition test data, so model choices are made without using its labels.
