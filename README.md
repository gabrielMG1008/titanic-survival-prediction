# Titanic - Machine Learning from Disaster

## About the Project

This project aims to develop a **Machine Learning** model capable of predicting which passengers survived the sinking of the **RMS Titanic**, using historical data provided by Kaggle.

The Titanic challenge is one of the most popular introductory datasets in Data Science and Machine Learning. It covers the complete workflow of a predictive model, including data exploration, preprocessing, feature engineering, model training, and performance evaluation.

---

## The Challenge

On **April 15, 1912**, during its maiden voyage, the RMS Titanic struck an iceberg and sank in the North Atlantic Ocean. The disaster became one of the deadliest maritime tragedies in history, resulting in the loss of approximately **1,502 of the 2,224 passengers and crew members** on board.

Although chance played a role in survival, several factors—such as **gender, age, passenger class, fare, and family size**—had a significant influence on a passenger's likelihood of surviving.

The objective of this challenge is to answer the following question:

> **What types of passengers were more likely to survive the Titanic disaster?**

To accomplish this, the dataset provides passenger information such as:

* Age
* Sex
* Passenger class
* Fare
* Number of family members aboard
* Port of embarkation
* Other demographic and travel-related features

---

## Objective

The goal is to build a **binary classification model** that predicts whether a passenger survived the disaster.

The target variable is:

* **0** → Did not survive
* **1** → Survived

The model is trained using the provided training dataset and then used to generate predictions for the test dataset.

---

## Evaluation

The competition uses **Accuracy** as the evaluation metric.

Accuracy measures the percentage of correctly classified passengers over the total number of predictions made.

A higher accuracy score indicates a better-performing model.

---

## Dataset

The dataset used in this project is provided by the **Titanic - Machine Learning from Disaster** competition on Kaggle.
